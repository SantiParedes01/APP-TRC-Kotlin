# APP-TRC-Kotlin

App móvil para el registro de jugadores de un club deportivo de rugby y hockey.
Trabajo de la materia Desarrollo de Aplicaciones Móviles I (UCES).

## Estado
En desarrollo. Se actualiza durante el cuatrimestre.

## Funciones
- En la pantalla "Acerca de", se puede observar el equipo que trabaja en la app y alguno de sus datos.
- En la pantalla "Jugadores", podemos ver un listado que está conectado a una base de datos donde se pueden ver,
agregar, modificar o eliminar jugadores con algunos de sus datos.

## Próximamente
- Agregar pantalla de "Inicio de Sesión/Cuenta".
- Función para agregar métodos de pago para la institución.
- Función para que jugadores puedan abonar su cuota por ahí sin la necesidad 
de acercarse a la administración de la institución.

## Tecnologías
- Kotlin
- Android Studio

## Cómo ejecutarlo
1. Clonar el repositorio.
2. Abrirlo con Android Studio.
3. Esperar a que termine la sincronización de Gradle.
4. Ejecutarlo en un emulador o en un celular.
